Kebijakan Privasi

Terakhir diperbarui: Juni 2026

1. Data yang Kami Kumpulkan

KapurPad tidak mengumpulkan, menyimpan, atau mengirimkan data pribadi Anda ke server manapun. Semua catatan, pengaturan, dan data lainnya disimpan hanya di perangkat Anda sendiri menggunakan penyimpanan lokal (localStorage / IndexedDB).

2. Penyimpanan Lokal

Semua data berikut tersimpan eksklusif di perangkat Anda:

  • Catatan teks dan daftar ceklis
  • Tag mood dan label catatan
  • Pengaturan tema dan preferensi tampilan
  • Data dzikir dan counter ibadah
  • PIN keamanan (disimpan terenkripsi lokal)

3. Izin Aplikasi

KapurPad hanya meminta izin berikut:

  • Notifikasi — untuk pengingat catatan yang Anda jadwalkan sendiri. Bersifat opsional.
  • Getaran (Vibration) — untuk umpan balik saat counter dzikir selesai.

Kami tidak meminta izin kamera, mikrofon, lokasi, kontak, atau akses file.

4. Layanan Pihak Ketiga

KapurPad menggunakan layanan berikut untuk fitur premium (opsional):

  • Midtrans — payment gateway untuk pembelian fitur Pro. Data pembayaran diproses langsung oleh Midtrans sesuai kebijakan privasi mereka. KapurPad tidak menyimpan data kartu atau rekening Anda.
  • Google Fonts — untuk menampilkan font. Google dapat mencatat permintaan font sesuai kebijakan privasi Google.

5. Backup & Ekspor

Fitur ekspor catatan menghasilkan file JSON yang disimpan ke perangkat Anda. File ini tidak dikirim ke manapun secara otomatis.

6. Anak-anak

KapurPad tidak ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data dari siapapun secara sadar.

7. Perubahan Kebijakan

Jika ada perubahan pada kebijakan ini, kami akan memperbarui tanggal di bagian atas halaman ini. Kami menyarankan Anda meninjau halaman ini secara berkala.
